**Tuần 1:** [Khởi tạo môi trường thực tập, thiết lập tài khoản Cloud AWS cá nhân và hoàn thành điều kiện nhận AWS credits.](1.1-week1/)

**Tuần 2:** [Nghiên cứu tổng quan Cloud Computing, mô hình tối ưu chi phí, AWS Global Infrastructure và dịch vụ quản lý truy cập IAM cơ bản.](1.2-week2/)

**Tuần 3:** [Hệ thống hóa kiến thức AWS Networking cốt lõi (VPC, Subnet, Routing, Security, Load Balancing) và tham gia Ngày hội Cộng đồng FCAJ.](1.3-week3/)

**Tuần 4:** [Thực hành Lab thực tế về AWS Networking: Khởi tạo VPC, cấu hình định tuyến Internet/NAT Gateway và thiết lập Security Group/NACL.](1.4-week4/)

**Tuần 5:** [Hoàn thiện Module Networking, chuyển giao nghiên cứu hạ tầng máy chủ ảo Amazon EC2, kiến trúc AMI, EBS và quy trình deploy ứng dụng.](1.5-week5/)

**Tuần 6:** [Nghiên cứu giải pháp lưu trữ dữ liệu với Amazon S3, tối ưu Storage Class, cấu hình Static Website Hosting, CORS và dịch vụ AWS Backup.](1.6-week6/)

**Tuần 7:** [Tìm hiểu sâu về Security & Access Control, giám sát tập trung với Security Hub, quản lý tài nguyên bằng Tags, IAM Policy/Role và KMS.](1.7-week7/)

**Tuần 8:** [Nghiên cứu Module Database (RDS, Aurora, Redshift, ElastiCache) và thực hành lab chuyển đổi/di trú dữ liệu sử dụng AWS DMS.](1.8-week8/)

**Tuần 9:** [Khảo sát mã nguồn dự án AI Image Upscaling Service, phân tích cấu trúc Frontend Next.js 14 App Router và thống nhất API Contract.](1.9-week9/)

**Tuần 10:** [Xây dựng giao diện vùng kéo thả tải ảnh (Upload Area) bằng react-dropzone, cấu hình tham số xử lý AI/Standard và thiết lập API Client.](1.10-week10/)

**Tuần 11:** [Tích hợp Frontend với các endpoint xử lý ảnh của Backend, kiểm soát các trạng thái phản hồi bất đồng bộ và thiết kế giao diện hiển thị kết quả.](1.11-week11/)

**Tuần 12:** [Tiến hành kiểm thử tích hợp toàn diện (E2E), tối ưu hóa mã nguồn production build, hoàn thiện tài liệu kỹ thuật và đóng gói báo cáo thực tập.](1.12-week12/)
